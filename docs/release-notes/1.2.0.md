## 新功能

- **应用自动更新**：启动时及每 6 小时自动检查新版本；支持「自动更新 / 仅检查并提醒 / 手动更新」三种方式。更新包下载失败自动重试，安装前校验大小与 SHA256；更新失败会自动回滚并提示。可在设置中查看当前版本、最新版本、更新日志与下载进度。
- **下载模板**：内置「最高画质 / 高清优先 / 兼容优先 / 节省空间 / 仅下载音频」预设，可新建、编辑、复制、重命名、删除自定义模板，并指定默认模板。新建下载时自动套用默认模板；对单个任务的修改不会影响模板，也可一键另存为新模板。
- **更多格式与参数**：封装格式 MP4 / MKV / WebM；音频格式（AAC、Opus，仅音频时可选 MP3 / M4A / Opus / FLAC / WAV）、音质与音轨（多语言配音视频）选择。格式不兼容时给出提示与一键推荐，并可开启自动转换。
- **文件命名与分类**：用 {title} {uploader} {date} {resolution} 等变量组合文件名，可按平台、作者或日期自动放入子文件夹。
- **批量链接可勾选**：一次粘贴多个链接时会逐个解析并列出标题、封面与时长，自行勾选要下载的项目；解析失败的链接会标出原因。批量任务统一套用所选模板。
- **下载管理**：队列中的任务可「优先下载」；长时间无进度会提示「下载停滞」；成功与失败通知可分别开关。
- **Deno 组件**：YouTube 的部分格式需要 JavaScript 运行环境，现可在设置中一键安装 Deno。

## 改进

- 「自动」画质改为在同一分辨率下优先选择码率最高的视频流。此前会优先选 AV1，导致 B 站等平台下载到码率很低的版本（例如 1080P 仅约 600 kbps，现约 2600 kbps）。
