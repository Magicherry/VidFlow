## 新外观

- **全新应用图标**：两条交叠的彩带组成「V」，既是 VidFlow 的首字母，也是向下的下载箭头，配一个播放标记。小尺寸（任务栏、托盘）使用加粗版本，更清晰。

## 改进

- **字幕语言改为勾选**：直接勾选简体中文、繁體中文、English、日本語、한국어，不必再手动填写语言代码；其他语言可在「其他语言」中补充。原有设置会自动对应到勾选项，折叠时显示当前保存的语言。
- **限速更直观**：改为「开关 + 数值 + 单位（KB/s / MB/s）」，折叠时显示当前状态；关闭限速后会记住上次的数值。
- **模板文件命名更易用**：提供常用命名格式可直接选择；点击「标题」「作者」「上传日期」等按钮即可插入变量；无法识别的变量会给出提示；预览以完整路径显示保存结果。
