## 新功能

- **本地字幕工具**：选择或拖入视频，即可检测字幕轨、识别语音生成字幕、提取已有文本字幕，或移除视频内的字幕轨。支持 SRT、VTT、ASS、LRC、TXT 和 Markdown。
- **字幕内嵌**：可将新生成的字幕或已有字幕文件加入视频，另存为 MKV，保留原视频和原有字幕轨。播放器中可切换字幕；不支持去除已烧录在画面中的文字。
- **视频封面预览**：本地视频卡片显示封面，系统无法提供缩略图时自动提取视频画面。初始界面与格式转换保持一致，选好视频后再显示处理选项。

## 修复与改进

- 修复 YouTube 英文自动字幕未正确列出、空文件被误判为字幕的问题。仅下载字幕时自动展开语言和格式选项，并隐藏视频内嵌开关。
- 字幕请求失败时保留已下载的视频并说明原因；没有识别到语音时不再生成空字幕或误报成功。
- 「重试字幕」直接修复原任务，保留语言、格式和内嵌设置，成功后才清除警告。暂停或重启后仍会继续字幕修复。
- 修复字幕转为 TXT、Markdown 时正常重复的句子被删除的问题。
- 打开预设编辑器时保留已保存的字幕语言，即使尚未解析视频或未安装语音识别模型。
- 下载、转换和本地字幕任务与组件替换互斥，避免更新正在使用的程序；应用更新提示覆盖各类后台任务。
- 捕获安装包重新校验、下载和启动过程中的异常，更新失败时可在应用内重试。
- 登录状态和直接请求使用的 Cookie 现在会检查有效期，忽略过期或无效的记录。
