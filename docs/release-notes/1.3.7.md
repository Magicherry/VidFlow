## 更新更快

- 应用更新和组件（yt-dlp、ffmpeg、Deno、aria2）改为多连接并行下载。经代理访问 GitHub 时单条连接经常很慢，现在 ffmpeg（约 200 MB）从数分钟缩短到约 20 秒，应用安装包只需几秒。

## 后台更新

- **自动更新组件**：原「自动更新 yt-dlp」扩展到所有组件。每天在后台检查一次，没有下载任务时自动更新 VidFlow 安装的组件；也修复了 yt-dlp 因 GitHub 接口限流而一直更新失败的问题。
- 组件安装会在后台继续，离开「关于与更新」页面也不会中断，回来可以看到进度。
- **退出时安装**：新版本下载完成后，退出 VidFlow 时会自动静默安装，下次打开即为新版本。

## 界面

- 标题栏右上角新增更新提示：有新版本时显示「新版本 x.y.z」，下载中显示进度，下载完成后显示「重启以更新」。
- 英文界面中「小红书」改为其国际名称 RedNote。

## 下载

- 提供 x64 与 ARM64 安装包，应用会按自身架构自动更新。
