## 新功能

- **字幕嵌入视频**：下载视频时可以把字幕作为字幕轨放进 MP4、MKV 或 WebM 文件，播放器里可以开关，每条字幕轨标有语言。
- **下载视频时也能选字幕**：「字幕」改为可展开的卡片，打开后可以选择字幕语言（某条字幕、自动生成的字幕或语音识别）和格式（SRT、WebVTT、ASS、LRC、TXT、Markdown），与「仅字幕」一致。

## 改进

- **更容易拿到字幕**：设置中的语言没有字幕时，会依次尝试视频原语言的自动字幕、其他语言的字幕，最后在已安装语音识别时自动识别生成。下载前，选项中会提示这个视频是否有字幕。
- **哔哩哔哩字幕需要登录**：未登录时会提示登录后才能获取字幕（包括 AI 字幕），并可直接前往账号页。
- **字幕失败不影响视频**：视频已下载但字幕没有获取到时，任务显示为完成并说明原因，可以点「重试字幕」单独获取。
- 选择语音识别时，不再同时下载平台字幕；没有识别到说话的视频（如纯音乐）不会留下空字幕文件。
