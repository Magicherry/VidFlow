## YouTube 下载大幅提速

- 新增 **aria2** 组件：YouTube、X 等海外视频的每个文件改为多连接同时下载。实测 1080p 视频从约 1 MB/s 提升到 30 MB/s 以上（取决于网络与代理）。
- 分片格式（如 YouTube 高帧率视频）同时下载 8 个分片。
- 新增「多连接加速」设置（默认开启）。在「关于与更新」中一键安装 aria2；新用户首次安装时会一并下载。
- 自动沿用 Windows 系统代理；多连接下载失败时会自动改用普通方式重试。
- 哔哩哔哩、抖音、微博、小红书仍使用单连接（国内 CDN 本身速度足够，且对多连接较敏感）。

## 修复

- 部分下载错误只显示 “ERROR:”，现在会显示完整原因（例如 HTTP 503）。
