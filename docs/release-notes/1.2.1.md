## 改进

- **设置页面重新整理**：功能入口更清晰，查找更快。
  - **下载模板**独立为左侧导航中的页面，分为「我的模板」和「内置预设」；点击自定义模板即可编辑。
  - **账号**独立为导航底部的页面，集中管理哔哩哔哩 / YouTube 登录及浏览器 Cookie、cookies.txt。
  - 应用更新、组件（yt-dlp / ffmpeg / Deno）与关于信息合并到「设置 › 关于与更新」子页面，可通过顶部路径返回。
  - 设置页只保留「常规 / 下载 / 网络 / 通知」四组；字幕、文件与兼容性、下载通知等不常改的选项收进可展开的分组。
- **更新提醒**：发现新版本时，导航栏「设置」会显示小圆点，「关于与更新」卡片显示新版本号。
- 首页提示、系统通知和错误信息中的跳转与说明已指向新的位置。
