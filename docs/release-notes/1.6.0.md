## 新功能

- **格式转换**：侧栏新增「格式转换」，可以转换电脑里已有的视频、音频、图片和字幕。
  - 点「添加文件」，或把文件、文件夹拖进页面；每个文件可以单独选择目标格式。
  - 视频：MP4、MKV、MOV、WebM 之间互转，也可以只提取音频（MP3、M4A、Opus、FLAC、WAV）。
  - 音频：MP3、M4A、Opus、FLAC、WAV。
  - 图片：JPG、PNG、WebP、BMP；转成 JPG 或 BMP 时，透明背景变为白色。
  - 字幕：SRT、WebVTT、ASS、LRC、TXT、Markdown；GBK 等旧编码的字幕也能正确读取。
  - 目标格式能直接容纳的音视频流会原样复制，几乎瞬间完成且画质不变，只有放不下的才重新编码。
  - 新文件保存在原文件旁边或指定的文件夹，不会覆盖已有文件；离开页面后转换会继续，侧栏会显示剩余数量。

## 改进

- **设置**：改为分类列表，「下载」「视频文件」「字幕」「网络与速度」「外观」「后台与通知」「附加组件」各有单独的页面，和「关于与更新」一样。
- **账号**：说明文字移到小标题下方，与其他页面一致。
