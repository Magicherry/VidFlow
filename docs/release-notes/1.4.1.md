## 修复

- **限速失效**：开启限速后，分片视频（HLS / DASH）的实际速度可能达到限速值的 8 倍。现在开启限速时分片改为单线程下载，总速度不再超过限速值。
- **WebM / WAV 下载失败**：开启「嵌入封面与元数据」时，这两种格式会在下载完成后报错。现在它们不再嵌入封面，其他元数据照常写入。
- 已下载好的更新不会再被定时检查改回「可下载」，退出时也能正常安装。
- 网速慢时，只要还在收到数据，组件和更新包的下载就不会判定失败。
- 重新运行设置向导后，「关于与更新」的组件状态会立即刷新。

## 下载模板

- **查看内置模板**：点击卡片或「⋯ → 查看设置」查看全部参数，也可以「复制后编辑」。
- **删除内置模板**：不需要的内置模板可以删除，点「还原内置模板」一键恢复。
- 模板卡片的小字会列出完整设置，包括默认值。

## 界面

- 页面标题下不再显示说明文字，有用的说明移到了相关内容旁边。
- 开关的文字跟随应用语言。
- 统一用词和写法：「重启以更新」「哔哩哔哩」「1080p」「内置模板」「组件」「移除」。
- 调整了重复的图标，统一了下拉框和按钮宽度。
- 「移除已结束」现在会先确认。

- 提供 x64 与 ARM64 安装包，应用会按自身架构自动更新。
