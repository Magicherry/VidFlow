## 新平台

- **抖音**：支持作品链接、App 分享口令和 v.douyin.com 短链接，可选择画质与编码（H.264 / H.265）。公开作品无需登录。
- **微博**：支持视频链接、带视频的微博和 t.cn 短链接，无需登录。
- **X（Twitter）**：支持帖子中的视频与 GIF，自动选择最高码率的版本，无需登录。
- **小红书**（实验性）：可识别笔记链接和 xhslink.com 短链接，部分内容可能无法下载。

## HDR、杜比视界、Hi-Res 与杜比全景声

- 解析后在视频卡片上标出 **HDR10 / 杜比视界 / Hi-Res 无损 / 杜比全景声**。
- 新增「画面」选项：自动（有 HDR 时优先 HDR）、杜比视界、SDR。
- 音频可选 **Hi-Res 无损（FLAC）** 或 **杜比全景声**；仅下载音频时新增「原始格式」，Hi-Res 音轨会保存为 .flac。
- 杜比视界与 Hi-Res 会自动保存为 MKV，并在选项中提示。

## 界面

- 新建下载页：新增「三种开始方式」和「支持的平台」卡片，显示各平台的登录状态。
- 账号页和视频卡片显示各平台的 logo；哔哩哔哩改用文字 logo。
- 精简了大量选项说明，去掉与标题重复的文字。

## 修复

- 微博选择低画质时可能下载到预览图片。
- 竖屏视频的画质按短边显示（1080×1920 显示为 1080p）。
- X 的最高画质会选中真正码率最高的 MP4，不再变成 MKV。
- 选择 MP4 时，B 站的无损音轨不会再让文件意外变成 MKV。
