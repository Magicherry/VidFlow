## 新功能

- **语音识别生成字幕**：没有字幕的视频，也能根据语音生成字幕。
  - 下载字幕时，在「字幕语言」中选择「语音识别生成」，支持自动检测、中文、英文、日文。生成的字幕可以保存为 SRT、WebVTT、ASS、LRC、TXT 或 Markdown 格式。
  - 识别在本机运行，不会上传任何内容。首次使用前，需要在「设置 → 附加组件」中下载识别模型：「高精度」约 547 MB，「快速」约 181 MB。
  - **显卡加速**：使用 NVIDIA 显卡的电脑可以另外下载约 653 MB，识别速度通常提升数倍；显卡不可用时会自动改用 CPU。
  - 中文识别结果会自动补充逗号和句号，TXT 和 Markdown 读起来更通顺。
- **视频和字幕放在同一个文件夹**：开启字幕后，每个视频都会放进以它命名的单独文件夹，字幕和弹幕也在里面；没有下载到字幕的视频仍直接保存。

## 改进

- **设置**：重新分组为「视频文件」「字幕」「附加组件」等，附加组件会显示占用的磁盘空间。
- **首次使用引导**：新增「更多功能」一步，可开启剪贴板监听、托盘，并下载语音识别；各步骤的说明更清楚。
- **安装程序**：采用 Windows 11 风格，跟随系统的浅色或深色模式，并加入欢迎页。

## 修复

- 安装程序的语言列表现在可以选择「简体中文」（之前显示为两个 English）。
- 修复正式版中抖音图文作品可能无法解析、等待后提示「无法获取这个抖音作品」的问题。
- 抖音下载任务的标题不再变成一串文件名。

## 下载

- 提供 x64 与 ARM64 安装包，应用会按自身架构自动更新。
